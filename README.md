# יובל — משחק מילים מרובה משתתפים

משחק מילים אונליין לטלפון (PWA), בנוי על Next.js ו-Redis (Upstash). אתר עצמאי, בנפרד מאתר הקניות.

## מבנה הקוד

```
app/page.tsx               דף המשחק (/)
app/layout.tsx             מטא-דאטה והתקנה כאפליקציה
app/api/alias/rooms/       API: יצירת חדר, הצטרפות, פעולות משחק, קריאת מצב
app/api/alias/ads/         API פרסומות: הצגה, ספירה, ניהול, דוחות
app/admin|advertise|report/  סביבת ניהול, טופס מפרסם, דוח למפרסם
components/alias/
  AliasClient.tsx          כל מסכי המשחק (כניסה, לובי, תור, סיכום, ניצחון)
  Splash.tsx               מסך פתיחה + שעון עם מחוג
lib/alias/
  game.ts                  כל חוקי המשחק ומכונת המצבים (צד שרת)
  store.ts                 שמירה ב-Redis + נעילה לכל חדר
  words.ts                 מאגר המילים
types/alias.ts             טיפוסים משותפים
public/                    אייקונים, manifest ו-service worker להתקנה כאפליקציה
app/globals.css            כולל אנימציית החול של שעון החול
```

## איך המשחק עובד

- **חדרים:** קוד בן 4 ספרות, סיסמה אופציונלית (נשמר רק גיבוב), 2-4 קבוצות עם שמות.
- **סנכרון:** בדיקת מצב כל ~1.2 שניות. כל חוקי המשחק והזמן נקבעים בשרת.
- **קלפים:** בכל קלף 8 מילים. כולם מתחילים בבועה 1, והמספר על הבועה שהקבוצה עומדת עליה קובע איזו מילה מסבירים בכל קלף.
- **בועות מיוחדות:** על הלוח 5 בועות עם מסגרת בלבד (מיקומן כמו בלוח האמיתי: 9, 21, 36, 52, 64 מתוך 70). קבוצה שנוחתת על אחת מהן בתנועה קדימה מקבלת ⭐, והסיבוב המיוחד מתקיים **בתור הבא שלה** (במקום סיבוב רגיל): בלי טיימר, המסביר מסביר 5 מילים לפי המספר שעל הבועה, כל הקבוצות מנחשות, והמסביר מסמן לכל מילה איזו קבוצה ניחשה ראשונה. אותה קבוצה מקבלת צעד קדימה.
- **צלילים:** בחמש השניות האחרונות של כל תור נשמעים פעמונים רכים בסולם עולה (5,4,3,2,1, ובשנייה האחרונה שלושה צלילים מהירים), ובסוף צלצול יורד נעים. הצלילים נוצרים בדפדפן, ואפשר להשתיק בכפתור 🔊. בתחילת כל תור נשמעת גם הכרזה בקול: "התור של [שם הקבוצה]" (בסיבוב מיוחד: "סיבוב מיוחד של [שם הקבוצה]"), בהקראה של הטלפון עצמו (עברית, he-IL).
- **התקדמות:** מילה שנוחשה = צעד קדימה, דילוג = צעד אחורה (אפשר לכבות). הלוח הוא ספירלה של בועות ממוספרות 1-8, והראשון שמגיע לדגל במרכז מנצח.
- **החלפת מסביר:** אי אפשר לדלג על תור של קבוצה. לפני תחילת הסיבוב אפשר רק להעביר את ההסברה לשחקן אחר **מאותה קבוצה** (חבר בקבוצה או המארח), והתור נשאר שלה.
- **שופט:** הקבוצה שלא בתור רואה את המילה והתוצאות, כדי לוודא שלא מרמים.
- **הזמנה:** קישור `/?room=1234` + שיתוף בוואטסאפ. הסיסמה לא נכללת בקישור.

## פרסומות והכנסות (מאושר על ידי בעל המשחק בלבד)

**כברירת מחדל אין שום פרסומת.** גם אם מפרסם שלח בקשה וגם אם אושרה, שום דבר לא מופיע עד שבעל המשחק
מדליק את המתג הראשי בסביבת הניהול.

| כתובת | מי | מה |
|-------|----|----|
| `/admin` | בעל המשחק | דשבורד: מאשר/דוחה/משהה פרסומות, מעלה תמונת באנר מהטלפון, עורך כותרת וקישור, קובע מחיר לכניסה, רואה חשיפות, כניסות וסכום לתשלום, מדליק וכבה את כל הפרסומות |
| `/advertise` | מפרסם | טופס הצעת פרסומת (נשאר "ממתין לאישור" ולא מוצג) |
| `/report?t=…` | מפרסם | דוח אישי: כניסות, חשיפות וכמה לשלם |

**כניסה לדשבורד (`/admin`):** שתי דרכים, אפשר להגדיר אחת או שתיהן.
1. **קישור במייל (מומלץ):** לוחצים "שלח לי קישור כניסה למייל", מקבלים מייל ל-`ADMIN_EMAIL` (ברירת מחדל gilbeny@gmail.com) עם קישור חד-פעמי בתוקף ל-15 דקות, ולחיצה עליו מכניסה לדשבורד ל-12 שעות. הגדרה: נרשמים בחינם ל-[Resend](https://resend.com) **עם אותה כתובת מייל**, יוצרים API Key, ומגדירים ב-Vercel את `RESEND_API_KEY`. (בחשבון חינמי של Resend אפשר לשלוח רק לכתובת שנרשמתם איתה, ואין צורך להגדיר דומיין.)
2. **מפתח:** משתנה `ADS_ADMIN_KEY` עם מפתח ארוך וסודי, שמקלידים בדף הכניסה.

בלי אף אחד מהשניים סביבת הניהול לא קיימת. ההגנות: קישור חד-פעמי שנשמר מוצפן, עוגייה HttpOnly, מקסימום 3 מיילים ב-10 דקות, ו-5 ניסיונות מפתח שגויים נועלים לדקה.

**תשלום לפי כניסות:** כל פרסומת מקושרת דרך `/api/alias/ads/go?id=…`, וכל כניסה נספרת לפני ההפניה למפרסם.
אותו מכשיר שנכנס לאותה פרסומת שוב בתוך שעה נספר פעם אחת, ובוטים ותצוגות מקדימות של קישורים לא נספרים.
המערכת מחשבת כמה כל מפרסם חייב (כניסות × מחיר), **אבל לא גובה כסף**: את הגבייה עושים מחוץ למערכת
(ביט, העברה בנקאית, חשבונית) לפי הדוח.

מקומות: מסך הכניסה, הלובי, וסיום תור/משחק. אף פעם לא באמצע תור ולא ליד כפתורי המשחק. כל פרסומת מסומנת "פרסומת".

**Google AdSense (אופציונלי):** מגדירים `NEXT_PUBLIC_ADSENSE_CLIENT` ו-`NEXT_PUBLIC_ADSENSE_SLOT_HOME/LOBBY/ROUNDEND`,
מוסיפים `public/ads.txt`, ומדליקים את המתג "Google AdSense" בניהול. ספונסר ישיר גובר על AdSense באותו מיקום.

> שימו לב: אם יש משתמשים באיחוד האירופי צריך באנר הסכמה לעוגיות לפני AdSense, ופרסומות לילדים
> מוגבלות בחוק. תמונות באנר מגיעות מקישור שהמפרסם נותן, ולכן בודקים כל פרסומת בתצוגה המקדימה לפני אישור.

## פריסה (אתר משלו ב-Vercel)

1. ב-Vercel: **Add New → Project**, בוחרים את הריפו `alias-games`.
2. **מסד נתונים:** ב-**Storage** בוחרים **Turso** (או Upstash Redis), יוצרים מסד ומחברים לפרויקט בכל הסביבות.
   Vercel מוסיף לבד את משתני הסביבה (`TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`). הטבלה נוצרת אוטומטית בשימוש הראשון.
3. אופציונלי לפרסומות: `ADS_ADMIN_KEY` (ראו למטה).
4. Deploy. הכתובת תהיה משהו כמו `https://yuval-games.vercel.app`, ואפשר לחבר דומיין משלך.

בלי מסד נתונים המשחק לא יעבוד באתר חי, כי כל בקשה יכולה להגיע לשרת אחר. לבדיקה: `/api/alias/health?check=1`.

## סטטיסטיקת משתמשים

בראש הדשבורד (`/admin`) כרטיס "כמה משתמשים יש לי": סה״כ משתמשים, חדשים היום, פעילים היום, פעילים ב-7 ימים, משחקים שנפתחו, וגרף של 14 הימים האחרונים.
"משתמש" = מכשיר או דפדפן ייחודי: בכניסה הראשונה נוצר מזהה אקראי אנונימי (בלי שם או מייל) ונשמר בדפדפן. מי שמשתמש בכמה מכשירים או מנקה את הדפדפן נספר כמה פעמים. הימים לפי שעון ישראל, והספירה מתחילה מרגע שהתכונה עלתה.

## אבטחה

- **סביבת הניהול** מוגנת במפתח `ADS_ADMIN_KEY` (השוואה בטוחה, נעילה לדקה אחרי 5 ניסיונות שגויים). בלי המפתח היא לא קיימת.
- **סיסמת חדר** נשמרת כגיבוב מוצפן (scrypt), לא נחשפת ללקוחות, ויש נעילה אחרי 5 ניסיונות שגויים.
- **חדרים** קריאים רק לשחקנים שבתוכם. כל חוקי המשחק והזמן נאכפים בשרת.
- **פרסומות:** כתובות יעד רק http/https, תמונות רק jpeg/png/webp עד ~300KB, וכל פרסומת מחכה לאישור שלך.
- בריפו אין סודות: המפתחות נמצאים רק במשתני הסביבה ב-Vercel. מומלץ לשמור את הריפו **פרטי**, להפעיל אימות דו-שלבי ב-GitHub וב-Vercel, ולהגן על הענף `main` (Settings → Branches).

## הרצה

```bash
npm install
npm run dev        # http://localhost:3000
```

ללא משתני סביבה המשחק שומר חדרים בזיכרון (מתאים לפיתוח). בפרודקשן נדרש מסד נתונים: Turso או Upstash Redis.

```
UPSTASH_REDIS_REST_URL=
UPSTASH_REDIS_REST_TOKEN=
```

(או `KV_REST_API_URL` / `KV_REST_API_TOKEN` של Vercel). אופציונלי: `NEXT_PUBLIC_SITE_URL` לתצוגה המקדימה של קישורי הזמנה.
